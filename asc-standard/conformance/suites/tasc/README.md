# TASC Suite

Validates TASC Assurance Pack conformance, including:

- Schema and required fields
- Topology interlock mediation and authority exclusivity
- Artifact hash integrity
- Signed operational log chain and signature
- Replay completeness
- TA2 attestation requirements
- EU incident and retention windows
- Dual transparency proof verification (`rekor`, `mirror`)
- Badge active/not-revoked status
