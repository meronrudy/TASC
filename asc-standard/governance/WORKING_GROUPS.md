# Working Groups

## Spec WG

- Owner: Spec Lead
- Scope: `ASC.md`, `spec/asc/*`, schema normative wording.
- Deliverables: versioned spec updates, glossary alignment, migration notes.

## Kernel WG

- Owner: Kernel Lead
- Scope: `reference/kernel/*`, runtime determinism, invariant enforcement.
- Deliverables: deterministic replay stability, kernel conformance tests, runtime regression triage.

## Assurance WG

- Owner: Assurance Lead
- Scope: `spec/tasc/*`, `schemas/*`, `tools/tasc-verify/*`, conformance vectors.
- Deliverables: check catalog integrity, negative vectors, verifier policy alignment.

## Security WG

- Owner: Security Lead
- Scope: attestation, PKI/HSM policy, transparency proofs, revocation lifecycle.
- Deliverables: trust policy updates, revocation policy freshness, incident trust response.

## Release WG

- Owner: Release Manager
- Scope: release pack generation, CI hard gates, branch protection controls.
- Deliverables: release rehearsals, GA sign-off package, branch protection status evidence.
